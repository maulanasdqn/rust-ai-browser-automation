What is Vision Mode?

Vision mode uses AI to "see" web pages like a human, identifying elements visually instead of using CSS selectors. This makes automation more robust and works even when websites change their structure.

✅ Works with any website design
✅ No CSS selector knowledge needed
✅ Handles dynamic content

Setup Instructions

1. Install ChromeDriver

Download ChromeDriver from:

https://chromedriver.chromium.org/

2. Start ChromeDriver

chromedriver --port=9515

3. Start UI Server

cargo run --bin automation-ui

4. Access Interface

http://localhost:3000
