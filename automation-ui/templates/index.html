ℹ️ About AC to Automation Converter

Welcome to the Acceptance Criteria to Automation Converter!

This tool helps QA engineers and developers automatically convert acceptance criteria written in Gherkin (BDD) format or plain text into executable browser automation scripts.

🚀 Features

  • Gherkin Support: Parse Given-When-Then scenarios
  • Multiple Script Formats: Generate MCP Browser, Selenium, and Playwright scripts
  • Simulation Execution: Test your workflows with simulated browser interactions
  • Smart Parsing: Intelligent extraction of actions from natural language
  • Workflow Management: Save and manage multiple automation workflows

📝 Supported Formats

Gherkin/BDD Format:

Scenario: User login
Given I am on the login page
When I enter valid credentials
And I click the login button
Then I should be redirected to dashboard

Plain Text Format:

User should be able to submit contact form
Navigate to contact page, fill form, submit, verify success

🔧 Generated Actions

  • Navigation: "visit", "navigate", "go to"
  • Interactions: "click", "press", "select"
  • Input: "type", "enter", "fill"
  • Verification: "see", "display", "show"

🎯 How to Use

  1. Enter your test title and feature name
  2. Paste your acceptance criteria in Gherkin or plain text format
  3. Add relevant tags for organization
  4. Choose whether to run simulation immediately
  5. Click "Convert & Generate" to create your automation workflow
  6. View generated scripts and execution reports
